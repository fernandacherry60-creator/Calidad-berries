# Calidad Berries Pro

Aplicación móvil para el control de calidad de berries, con acceso de administración y trabajadores, captura de muestreos y sincronización con Supabase.

## 📱 Descargar APK para Android

**[Consultar la última versión APK en GitHub Releases](https://github.com/tropicana1930-ship-it/Calidad-berries/releases/latest)**

> **Estado:** pendiente de publicar la primera APK de prueba. El enlace anterior mostrará la versión más reciente cuando se haya publicado una release con el archivo `.apk`. No confundir con el archivo `.aab`, que se utiliza para Google Play.

La APK se generará con **Expo EAS Build**, plataforma **Android** y perfil **`preview`**. Una vez completada y verificada la compilación, el archivo se adjuntará a una release de GitHub para que se pueda descargar desde esta página.
